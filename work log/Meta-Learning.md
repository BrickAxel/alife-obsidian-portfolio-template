The process of learning how to learn
Challenges are common. especially surrounding forgetting.
End goal of being able to apply learned skills from one task to another task and understanding how the new task could help better the understanding of the old task.
Assume limited storage and energy, not because infinite isn't possible in theory but because implementation is beneficial and budgets exist.
In order to not forget things and learn over time a few things can be done
rehearsal: store data to use again in the future.
regularization-based: penalize changes to weights that are important to understanding other things.
architectural changes: expand parameters to allow for new learning
games with similar basic set up have decent transfer 
If a model is successful in being able to understand multiple types of game then it will get better at one even if it hasn't played it in a while. 
The more similar a task the more should transfer.
Noise can also become a problem if the training set didn't have any the model may not be able to cope in real world cases.
Sustainability would be nice.
Different models have different strengths and weaknesses as shown but improvements are being made all the time.
